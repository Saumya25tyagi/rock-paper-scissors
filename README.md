# ✊✋✌️ Rock Paper Scissors Game

A fun and interactive Rock-Paper-Scissors game built using HTML, CSS, and JavaScript. Challenge the computer and see if you can win the game by making the right choice!

## 🔗 Live Demo
[Play Rock Paper Scissors](https://saumya25tyagi.github.io/rock-paper-scissors/)

## ✨ Features
- Play against the computer
- Random computer moves
- Track your score
- Interactive and stylish buttons

## 🛠️ Technologies Used
- **HTML**: Markup for the game structure.
- **CSS**: Styling the buttons and layout to make it visually appealing.
- **JavaScript**: Game logic and interactions, including random computer move generation and score tracking.
